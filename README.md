## Sobre

Estudante de desenvolvimento, com formação em andamento em HTML e CSS pela Fundação Bradesco e em Arquitetura de Sistemas pela FAT - Fundação de Apoio à Tecnologia. Desenvolvo interfaces com atenção à organização do código e à experiência de navegação, e estudo a construção de APIs com foco em desempenho, containerização, integração contínua e observabilidade.

## Projetos em destaque

**DeliveryTech: API de delivery**
API REST de um sistema de pedidos de comida, desenvolvida com Java e Spring Boot. O projeto inclui cache, execução em contêineres com Docker Compose e MySQL, integração contínua com GitHub Actions e observabilidade (métricas, verificação de saúde e rastreamento) com Prometheus e Zipkin. Desenvolvi também, por iniciativa própria, um front-end de testes para consumir a API.
[Repositório](https://github.com/giuliasamogin/deliverytech)

**Fluffify: e-commerce de pet shop**
Site multipágina de uma pet shop fictícia, construído em duas etapas. A segunda versão reúne catálogo por categoria, carrinho, lista de favoritos, cálculo de frete, cupom de desconto, modo escuro e quiz de recomendação.
[Parte 1](https://giuliasamogin.github.io/Fluffify/Parte-1/) | [Parte 2](https://giuliasamogin.github.io/Fluffify/Parte-2/) | [Repositório](https://github.com/giuliasamogin/Fluffify)

**Helena Vidigal: site para nutricionista**
Projeto final do curso de HTML: site institucional completo com identidade de marca para uma nutricionista fictícia, com 19 páginas, incluindo quiz, biblioteca de materiais, FAQ e política de privacidade conforme a LGPD.
[Repositório](COLE-AQUI-O-LINK-DO-REPOSITORIO-DA-HELENA)
