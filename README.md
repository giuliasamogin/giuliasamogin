## `SOBRE`

Desenvolvedora back-end em formação, com foco em Java e Spring Boot. Desenvolvo APIs REST com cache, containerização em Docker, integração contínua com GitHub Actions e observabilidade com Prometheus e Zipkin, e construo interfaces web com HTML, CSS e JavaScript, priorizando a organização do código e a experiência de navegação.

Tenho interesse em Inteligência Artificial e Machine Learning e estou construindo a base de engenharia de software necessária para atuar nessa área.

## `PROJETOS`

**DeliveryTech: API de delivery (projeto principal)**

<img src="https://img.shields.io/badge/Java-8B5CF6?style=flat-square&logo=openjdk&logoColor=white" alt="Java" /> <img src="https://img.shields.io/badge/Spring_Boot-171117?style=flat-square&logo=springboot&logoColor=8B5CF6" alt="Spring Boot" /> <img src="https://img.shields.io/badge/Docker-171117?style=flat-square&logo=docker&logoColor=8B5CF6" alt="Docker" /> <img src="https://img.shields.io/badge/MySQL-171117?style=flat-square&logo=mysql&logoColor=8B5CF6" alt="MySQL" />

API REST de um sistema de pedidos de comida, desenvolvida com Java e Spring Boot. O projeto inclui cache, execução em contêineres com Docker Compose e MySQL, integração contínua com GitHub Actions e observabilidade (métricas, verificação de saúde e rastreamento) com Prometheus e Zipkin. Desenvolvi também, por iniciativa própria, um front-end de testes para consumir a API.

[Repositório](https://github.com/giuliasamogin/deliverytech)

**Fluffify: e-commerce de pet shop (projeto acadêmico)**

<img src="https://img.shields.io/badge/HTML-8B5CF6?style=flat-square&logo=html5&logoColor=white" alt="HTML" /> <img src="https://img.shields.io/badge/CSS-171117?style=flat-square&logo=css3&logoColor=8B5CF6" alt="CSS" /> <img src="https://img.shields.io/badge/JavaScript-171117?style=flat-square&logo=javascript&logoColor=8B5CF6" alt="JavaScript" />

Site multipágina de uma pet shop fictícia, desenvolvido no curso de HTML e CSS da Fundação Bradesco e construído em duas etapas. A segunda versão reúne catálogo por categoria, carrinho, lista de favoritos, cálculo de frete, cupom de desconto, modo escuro e quiz de recomendação.

**Helena Vidigal: site para nutricionista (projeto acadêmico)**

<img src="https://img.shields.io/badge/HTML-8B5CF6?style=flat-square&logo=html5&logoColor=white" alt="HTML" /> <img src="https://img.shields.io/badge/CSS-171117?style=flat-square&logo=css3&logoColor=8B5CF6" alt="CSS" /> <img src="https://img.shields.io/badge/JavaScript-171117?style=flat-square&logo=javascript&logoColor=8B5CF6" alt="JavaScript" />
