## `SOBRE`

Estudante de desenvolvimento de software, com formação em andamento em HTML e CSS pela Fundação Bradesco e em Arquitetura de Sistemas pela Fundação de Apoio à Tecnologia (FAT). Dedico-me ao desenvolvimento de interfaces web, com ênfase na organização do código e na experiência de navegação, e à construção de APIs REST em Java com Spring Boot, abrangendo cache, containerização com Docker, integração contínua com GitHub Actions e observabilidade com Prometheus e Zipkin.

Meu objetivo é consolidar uma base sólida em engenharia de software para atuar, futuramente, na área de Inteligência Artificial e Machine Learning.

**Foco atual**

- Desenvolvimento de APIs REST com Java e Spring Boot
- Containerização com Docker e Docker Compose
- Integração contínua com GitHub Actions
- Observabilidade com Prometheus e Zipkin
- Desenvolvimento de interfaces web com HTML, CSS e JavaScript

**DeliveryTech: API de delivery**

<img src="https://img.shields.io/badge/Java-8B5CF6?style=flat-square&logo=openjdk&logoColor=white" alt="Java" /> <img src="https://img.shields.io/badge/Spring_Boot-171117?style=flat-square&logo=springboot&logoColor=8B5CF6" alt="Spring Boot" /> <img src="https://img.shields.io/badge/Docker-171117?style=flat-square&logo=docker&logoColor=8B5CF6" alt="Docker" />

API REST de um sistema de pedidos de comida, desenvolvida com Java e Spring Boot. O projeto inclui cache, execução em contêineres com Docker Compose e MySQL, integração contínua com GitHub Actions e observabilidade (métricas, verificação de saúde e rastreamento) com Prometheus e Zipkin. Desenvolvi também, por iniciativa própria, um front-end de testes para consumir a API.

[Repositório](https://github.com/giuliasamogin/deliverytech)
